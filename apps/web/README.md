# Web dashboard (placeholder)

Build starts **Nov 24** per the plan in the prep file. Planned views:

- **Watchlist** — every tokenized stock: DEX price vs NAV, premium/discount,
  momentum badges, feed-freshness indicator.
- **Agent page** — paper-portfolio equity curve, holdings in share-equivalent
  units (balance × multiplier), full decision log with rationale and
  attestation links.
- **Research feed** — the agent's daily briefs and per-decision notes.
- **Run your own** — connect a wallet, clone the agent's strategy as your own
  paper portfolio.

Compliance furniture from day one: "not financial advice" disclaimers, no
return promises, no claims of rights in underlying companies, and a notice
that tokenized stocks are for eligible jurisdictions outside the U.S.
(this project does not enable trading for U.S. users).

`index.html` in this folder is a static placeholder until the real app lands.
